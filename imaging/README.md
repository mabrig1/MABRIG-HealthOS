# MONAI imaging research lab
This is a separate local CPU Python runtime, not a Cloudflare Worker. No external images, DICOM or NIfTI uploads, pretrained weights, medical inference, clinical deployment or paid calls. The synthetic circle is generated by code. The threshold is not a learned model. The untrained MONAI U-Net is only a forward-pass shape/finiteness check and does not produce the displayed mask.

## Source and install
MONAI upstream: https://github.com/Project-MONAI/MONAI, release 1.6.2, commit a85d75e11cdd9c6d6d13500dc7f3960dd07dd7d3. The git submodule pins the original source without flattening the upstream history into HealthOS. Apache-2.0 text is preserved in third_party/MONAI-LICENSE. MONAI copyright belongs to its contributors, not MABRIG.

From the repository root (Python 3.12 recommended):
```bash
git submodule update --init --recursive
python -m venv .venv
# Activate .venv (Windows PowerShell: .venv\\Scripts\\Activate.ps1; Linux/macOS: source .venv/bin/activate)
python -m pip install --upgrade pip
# CPU PyTorch (Linux/Windows; macOS use normal pip install torch==2.8.0)
python -m pip install torch==2.8.0 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r imaging/requirements.txt
python -m unittest imaging.test_synthetic_lab
python -m imaging.synthetic_lab
```
The runtime uses the pinned released package (not an editable install of the cloned checkout). The source clone is available for review. Open root index.html, select Medical imaging lab and import monai-synthetic-report.json. File contents never leave the browser. No medical accuracy claim; imported files are unauthenticated. CI's Python workflow is manual to avoid automatic large dependency downloads. The ordinary web CI does not run PyTorch.
