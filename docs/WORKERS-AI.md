# Workers AI owner research pilot

Deploy main with Wrangler; AI and HEALTH_AI_QUOTA (SQLite Durable Object) are declared in wrangler.jsonc. No Cloudflare REST token is needed for env.AI. Verify Workers Free plan in account billing, monitor account-wide neurons (including SwarmLab); do not enable on paid plan. Set HEALTH_AI_ENABLED=true and CF_AI_FREE_PLAN_CONFIRMED=true consistently in production config; add secret HEALTH_AI_OWNER_TOKEN using a unique random 32–200 character value. Never reuse a Cloudflare API token or SwarmLab bridge token. Use the owner pilot in HealthOS. Five global reservations per UTC day, max 300 output tokens; no retries/fallback, failed calls count. Not a guarantee of total account usage or cost; free-plan restriction is an operator attestation, not a billing API verification. Keep disabled if uncertain. No patient input or medical use; research-method drafts only. No logs or persistence of prompts or outputs by application. Provider processing subject to Cloudflare terms. Tests use mocked AI; actual inference requires deployment and operator authorization. Disable with HEALTH_AI_ENABLED=false. Existing OpenRouter and Resend secrets not used by this pilot.
