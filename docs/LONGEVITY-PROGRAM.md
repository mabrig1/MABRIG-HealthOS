# Healthy aging program v0.13
The upgrade is inspired by a supplied educational guide covering photoprotection, lifestyle, cosmetic ingredients, professional care and long-term tracking. The supplied PDF is not included or reproduced in this public repository. Independent references: AAD https://www.aad.org/public/everyday-care/skin-care-secrets/anti-aging/retinoid-retinol ; AAD pregnancy https://www.aad.org/public/everyday-care/skin-care-secrets/routine/pregnancy-skin-care ; WHO https://www.who.int/initiatives/behealthy/physical-activity ; FDA https://www.fda.gov/medical-devices/aesthetic-cosmetic-devices/dermal-fillers-soft-tissue-fillers . These sources support educational framing, not individual eligibility or a clinical claim.
Manual region selection uses an original diagram, not automated landmark detection. Routine uses chosen skin preference, not imagery or medical records. Retinoids and procedures are educational only; no dosing, eligibility, treatment sequencing or device settings. Habit tracking is a 30-day practice, not a promised cosmetic outcome. Five boolean values per day, no dates, names, photos, medications or demographic information. Session only with explicit local JSON export/import (unencrypted; protect exported files); no automatic persistence or uploads. Clear resets memory only. The app suggests private standardized photography outside the app, does not store or compare face images. Device testing and clinician review remain required. No new API calls.
